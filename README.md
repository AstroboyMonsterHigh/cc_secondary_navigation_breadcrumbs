## 🧪 The Objective

In web architecture, orienting the user is critical. Without clear navigation, a user becomes disoriented, increasing the bounce rate and breaking user trust. This lab focuses on transforming a raw, unformatted HTML list into an industry-compliant, left-aligned breadcrumb navigation bar located right beneath the primary navigation header.

### 🛡️ Core Expectations Met:
* **Spatial Efficiency:** Configured horizontally to minimize structural real estate.
* **Contextual Breadth:** Hinting at the site’s structural depth (e.g., matching expectations like `Fashion > Shoes`, indicating other categories exist).
* **Standard Demarcation:** Utilizing standard delimiters (`>` or `/`) via CSS pseudo-elements to display clear parent-to-child folder inheritance.

## 💻 Tech Stack

* **HTML5:** Structuring semantic navigation elements.
* **CSS3:** Implementing inline-block/flexbox properties and list formatting rules.

## 💡 "Did You Know?" – The Attack Surface Connection
> 🔐 **The Perimeter Insight:** From a security standpoint, breadcrumb structures often mirror the underlying server directory hierarchy or API routing architecture. Attackers performing **Directory Traversal** or **Forced Browsing** attacks frequently look at visual breadcrumbs to infer hidden pathways or guess administrative URLs (e.g., mapping out `Domain > Admin > ControlPanel` even if structural restrictions are poorly enforced). Clean, abstracted UI architecture combined with robust server-side Access Control Lists (ACLs) ensures your map guides users safely without exposing the layout to bad actors.
